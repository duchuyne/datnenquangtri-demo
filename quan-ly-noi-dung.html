Quản Lý Nội Dung Không Cần Chuyên Môn

File này giúp sửa nội dung text, ảnh, video cho các phần của web một cách dễ dàng. Đã bỏ qua theo yêu cầu: Tổng Quan, Vị Trí, Tin Tức.

Cách dùng nhanh: 1) Mở file này trong trình duyệt, 2) Sửa nội dung, 3) Bấm "Tải index.html đã cập nhật".
Muốn cập nhật trực tiếp lên host: sửa mật khẩu trong file api-save-index.php, sau đó nhập mật khẩu và bấm "Lưu lên host".
Tìm ảnh theo tên file và chèn nhanh vào ô đang chọn
Mẹo: hãy click vào ô src trước, rồi tìm ảnh và bấm “Chèn vào ô đang chọn”.
Chưa có kết quả tìm kiếm.
Chưa nạp được file. Hãy bấm "Nạp index.html cùng thư mục" hoặc "Chọn file index.html thủ công".
Hãy nạp file index.html để bắt đầu chỉnh sửa.
